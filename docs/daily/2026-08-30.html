Model Releases

Introducing Hy4 PreviewSimon Willison

Tencent has released Hy4 Preview, an open-weight text-only large language model with 770 billion total parameters and 49 billion active parameters, using a mixture-of-experts architecture. The model supports a 1 million token context window and weighs 1.56 TB on Hugging Face. This represents a significant size increase over Tencent's previous Hy3 model, released in July, which had 295 billion total parameters, 21 billion active parameters, and a 256,000-token context window. The release adds another large-scale open-weight model to a competitive landscape that includes offerings from Meta and Mistral.

Open-Source Tools

Open Oscar Server: open-source server compatible with AIM and ICQ clientsHacker News

Developer mk6i has published Open Oscar Server, an open-source implementation of the OSCAR protocol used by AOL Instant Messenger and ICQ, allowing vintage clients from the late 1990s and 2000s to connect to a self-hosted server. The project enables users to run a private instant messaging environment compatible with original AIM and ICQ software without relying on AOL's now-defunct infrastructure. OSCAR, which stood for Open System for Communication in Realtime, was the proprietary protocol that underpinned both services at their peak of popularity. The repository is hosted on GitHub and accepts contributions, making it part of a small but active community preserving legacy internet communication protocols.
