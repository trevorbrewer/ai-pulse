Beyond Scores: Understanding LLM-as-a-Judge Mechanisms in Summarization EvaluationarXiv

Researchers published a paper investigating how LLM-based evaluators internally assign quality ratings to natural language generation outputs, a process that until now has been poorly characterized despite widespread deployment. The study uses an eight-attack perturbation taxonomy targeting two evaluation dimensions — Readability and Adequacy — to probe the internal mechanisms of LLM judges during summarization evaluation. The work is relevant because LLM-as-a-judge systems are used both as scoring tools and as automated training signals, meaning opaque failure modes in these systems could propagate into model training pipelines.

Efficient SWE Agent Benchmarking via Trajectory-Aware EvaluationarXiv

Researchers have proposed a trajectory-aware evaluation method for software engineering (SWE) agents that reduces the cost of benchmarking on realistic coding tasks. Standard evaluation on benchmarks like SWE-bench is expensive because each task can require multi-step code exploration, modification, and test execution across potentially hundreds of tasks. Existing subset-selection methods estimate full-benchmark performance using only pass/fail outcomes or static task semantics, ignoring the actual sequence of actions an agent takes. The new approach incorporates agent trajectories — the step-by-step decision paths — into the evaluation framework, aiming to produce more accurate performance estimates while requiring fewer full task evaluations.
