Open-Source Tools

New release of LLM adds support for reasoning traces, OpenAI Responses, server-side tools, and smarter loggingSimon Willison

Simon Willison released LLM 0.32, a command-line and Python tool for interacting with large language models, describing it as the most significant update since the project's initial launch. The release adds visible reasoning traces, server-side provider tools, a redesigned content-addressable SQLite logging system, and new features enabled by the OpenAI Responses API. It also ships alongside a major update to the llm-anthropic plugin, version 0.26, which integrates the new capabilities.

llm-anthropic 0.26Simon Willison

The llm-anthropic plugin was updated to version 0.26 alongside the LLM 0.32 release, adding support for three new Anthropic models: claude-fable-5, claude-sonnet-5, and claude-opus-5. The update introduces server-side tools — WebSearch, WebFetch, CodeExecution, and AnthropicMCP — accessible via LLM's -T interface or the Python tools= parameter. The previous -o web_search* options have been removed in favor of the unified -T WebSearch syntax, and the plugin now requires llm>=0.32.

Research Papers

ParVL: Parallel Scaling and Expandable Compute Allocation for Multimodal LLMsarXiv

Researchers introduced ParVL, a framework that addresses a structural inefficiency in multimodal LLMs: most existing architectures fix the compute budget split between the Vision Transformer and the LLM backbone, regardless of what a given task actually requires. ParVL proposes parallel scaling that allows compute to be dynamically redistributed between the two components, reducing both memory overhead and latency compared to approaches that simply add more parameters or extend sequential inference. The work targets the observation that vision-heavy tasks and text-heavy tasks have substantially different optimal compute allocations, which static architectures cannot exploit.

SocietyBench: Forecasting Counterfactual Social-World EvolutionarXiv

Researchers introduced SocietyBench, a benchmark designed to measure how well LLMs can forecast how real social events unfold, a capability distinct from task completion benchmarks focused on coding or GUI interaction. The benchmark constructs counterfactual scenarios from actual social events and asks models to predict the downstream evolution of those scenarios, providing a structured way to probe social world modeling. The authors argue that social forecasting ability has been largely unmeasured despite being relevant to applications where models are expected to reason about human behavior at scale.

WorldCup Arena: Prospective, Leakage-Free Evaluation of Frontier LLMs on a Live TournamentarXiv

Researchers conducted a 39-day prospective evaluation of six frontier LLMs during the 2026 FIFA World Cup, asking models to make predictions before matches occurred rather than evaluating them on historical data that could already exist in training sets. All six models had extended thinking enabled and native server-side web search access, placing them in conditions closer to real deployment than typical benchmark setups. The design directly addresses the memorization problem that undermines most forecasting benchmarks, because no correct answer existed online at prediction time.

TurnSight: Turn-Level Hindsight Self-Distillation for Tool-Integrated ReasoningarXiv

Researchers proposed TurnSight, a method for improving tool-integrated reasoning in LLMs by applying self-distillation at the individual turn level rather than across entire trajectories. Existing reinforcement learning approaches for tool-using agents typically assign credit at the trajectory level, which provides coarse feedback in long multi-step tasks where errors compound across many tool calls. TurnSight uses teacher branches with privileged context to generate denser turn-level training signals, aiming to improve fine-grained credit assignment without requiring external supervision.

PAST-Bench: Benchmarking the Foundations of Recursive Self-Improvement in Personal AgentsarXiv

Researchers have introduced PAST-Bench, a benchmark designed to systematically evaluate whether personal AI agents can leverage accumulated experience to improve their future behavior — the core requirement of recursive self-improvement. The benchmark targets personal AI agents specifically because they naturally retain information across sessions, including user preferences, task histories, tool routines, and learned skills, making them a concrete testbed for studying this capability. Prior to this work, no standardized evaluation existed to measure whether such retained experience actually translates into measurable performance gains over time. PAST-Bench aims to fill that gap by providing structured tasks and metrics that probe the foundational mechanisms underlying self-improvement in agent systems.
