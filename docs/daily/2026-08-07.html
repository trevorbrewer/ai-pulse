Learning When to Trust via Selective Context Preference OptimizationarXiv

Researchers reframe the problem of language model context sensitivity as "selective trust" rather than simple context acceptance or rejection. They introduce MIST, a human-annotated benchmark designed to evaluate whether a model can distinguish trustworthy external signals from misleading ones. The paper argues that training models to unconditionally resist external context creates models that appear robust but fail in practical retrieval-augmented settings where context is genuinely informative.

The Bitter Lesson of Tool CallingarXiv

This paper evaluates programmatic tool calling — where LLM agents write scripts to chain and parallelize tool calls rather than issuing rigid JSON requests — against conventional tool-use methods across multiple model generations. The study uses an established benchmark under real-world task conditions to produce the first systematic comparison of the two paradigms. Results are intended to inform practitioners about whether the added complexity of code-based tool calling translates to measurable performance gains.

An Optimal Agnostic PAC AlgorithmarXiv

The paper constructs a learner that achieves the statistically optimal risk bound in the agnostic PAC learning setting for any hypothesis class of finite VC dimension d. From a sample of size n, the algorithm guarantees with probability at least 1–δ that excess risk is bounded by a term scaling as the square root of L*(d + log(1/δ))/n plus a lower-order term, where L* is the best-in-class risk. The result closes a long-standing theoretical gap by matching known lower bounds without additional assumptions.

AV-AIVAT: 74x Cheaper Agent Evaluation with Certified Anytime-Valid Stopping in Imperfect-Information GamesarXiv

AV-AIVAT introduces an evaluation framework for comparing AI agents in imperfect-information games that uses anytime-valid statistics to allow early stopping as soon as a result is statistically certifiable. The method achieves up to 74 times the evaluation efficiency of fixed-budget baselines, reducing the number of games — and therefore compute or expert time — required to distinguish agent strength. The approach addresses a known failure mode of optional stopping under standard confidence intervals, which invalidates statistical guarantees.

The Low Frequency Trap: Video Language Models Fail at Simple Event BookkeepingarXiv

The paper identifies a systematic failure in video-language models: they perform poorly at tracking low-frequency events in video, a task the authors term event bookkeeping. Existing benchmarks conflate event count, rate, duration, and visual complexity, making it hard to isolate which factor causes errors; the authors introduce trace-grounded parametric probes that audit model-reported events against executable ground truth. The findings suggest that current video-language models exploit statistical regularities in training data rather than performing genuine temporal reasoning.

Resourced Authority: A Mechanism-Design Model for Participatory Governance of Deployed AI AgentsarXiv

This paper presents a formal mechanism-design model for governing deployed AI agents through continuous participatory oversight rather than one-time pre-deployment review. The central principle is that compute budgets serve as an effective governance lever, making authorization self-enforcing by tying an agent's capabilities to allocated resources. The authors situate the framework within the broader "Safe AI" paradigm and argue that resource allocation provides a more tractable control point than behavioral constraints alone.

CalibForge: Adversarial Solver Calibration for Scaling Learnable Terminal TasksarXiv

CalibForge is a task-synthesis system that generates training tasks for terminal agents calibrated to a specific solver's difficulty level, rather than simply verifying that tasks are solvable. The system uses verified solver behavior to iteratively revise candidate tasks until they fall within an appropriate challenge range for learning. The motivation is that executable validation alone — confirming a task is feasible — does not reveal whether the task will drive meaningful skill improvement during training.
