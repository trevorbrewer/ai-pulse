Open-Source Tools & Protocols

Stateless MCP has recaptured my interest (and inspired mcp-explorer and datasette-mcp)Simon Willison

The Model Context Protocol specification was updated to version 2026-07-28, colloquially called MCP 2.0 or Stateless MCP, representing the most significant revision since the protocol launched. The stateless design eliminates the need for persistent server connections, which Simon Willison describes as reigniting his interest in the protocol and prompting him to build two new tools: mcp-explorer and datasette-mcp. MCP defines a standard interface for exposing data and tools to AI models, and the stateless approach is expected to simplify deployment and integration.
